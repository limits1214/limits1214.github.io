# 사슬팔 연결과 스윙·당겨 이동

## 문제 상황

산나비 모작에서 사슬팔을 지형에 걸고 흔들리다가 원하는 순간 당겨 올라가는 이동을 구현하고자 했습니다. 갈고리를 발사하는 것뿐 아니라 지형에 걸린 뒤 흔들리는 움직임과 당겨 올라가기 및 줄 놓기를 자연스럽게 연결해야 했습니다.

Win32 API 기반 개인 프로젝트에서 플레이어와 갈고리를 별도 객체로 구성했습니다. 플레이어는 조작과 이동 상태를 맡고 갈고리는 비행과 지형 충돌을 처리한 뒤 지형에 걸린 결과를 플레이어에 전달하도록 나눴습니다.

## 접근 방법 검토

목표로 한 스윙과 당겨 올라가는 조작에 맞춰 갈고리가 걸린 위치와 줄 길이로 플레이어 위치를 직접 구했습니다.

멀리 겨냥할 수 있는 사거리와 지형에 연결된 뒤 흔들릴 줄 길이도 구분해 조준 범위와 스윙 동작을 따로 조절하도록 했습니다.

## 해결 과정

### 갈고리를 조준하고 지형에 연결하기

마우스 위치에는 화면이 스크롤된 거리를 더해 플레이어와 같은 게임 좌표로 맞췄습니다. 플레이어에서 마우스를 향하는 각도를 `atan2(dy, dx)`로 구해 갈고리를 발사하고 플레이어와의 거리가 400을 넘으면 제거하도록 했습니다.

갈고리와 지형의 사각형이 겹치면 갈고리를 지형 경계로 옮기고 이동을 멈춥니다. 플레이어에는 어떤 지형에 어느 방향으로 부딪혔는지 전달합니다. 사슬팔을 걸 수 있는 지형에만 연결하고 같은 충돌을 여러 번 알리지 않도록 표시를 남겼습니다.

### 줄 길이와 경과 시간으로 스윙 계산

갈고리가 지형에 걸렸을 때 거리가 200보다 크면 플레이어를 갈고리 쪽으로 당겼습니다. 거리가 200보다 짧아지면 실제 거리를 줄 길이로 저장했습니다. 갈고리 바로 아래를 0도로 삼아 캐릭터가 기울어진 각도를 시작 각도로 저장하고 경과 시간을 0으로 초기화했습니다.

![발사 거리 400과 스윙 전 당김 기준 200의 차이](/img/projects/sanabi/grapple-distance.svg)

스윙에는 작은 각도에서의 진자 운동 공식을 사용했습니다. 시작 각도에서 정지한 상태를 기준으로 줄 길이와 중력 설정값을 이용해 왕복 운동의 주기를 결정하는 각주파수를 구했습니다. 이를 바탕으로 시간에 따른 각도를 계산했습니다.

$$
\begin{aligned}
\omega &= \sqrt{\frac{g}{L}} \\
\theta(t) &= \theta_0 \cos(\omega t) \\
x(t) &= x_a + L\sin\theta(t) \\
y(t) &= y_a + L\cos\theta(t)
\end{aligned}
$$

여기서 $L$은 줄 길이이고 $g$는 중력 설정값입니다. $\theta_0$는 시작 각도이며 $t$는 스윙 시작 후 경과 시간입니다. 갈고리가 걸린 지점 $(x_a, y_a)$를 기준으로 각도를 플레이어 위치로 변환했습니다.

위 수식을 코드로 표현하면 다음과 같습니다.

```cpp
const float gravity = 1100.f;
const float omega = sqrtf(gravity / length);
const float angle = startAngle * cosf(omega * elapsed);

playerX = anchorX + sinf(angle) * length;
playerY = anchorY + cosf(angle) * length;
```

화면의 Y축이 아래로 증가하므로 각도 0은 갈고리 바로 아래를 뜻합니다. `gravity`는 실제 중력가속도 대신 게임의 좌표와 움직임에 맞춰 조정한 값입니다. 좌우 입력은 시작 각도를 바꿔 스윙 폭에 반영하고 플레이어의 좌우 이동과 연결했습니다.

자동 당김이나 천장 부착 중에는 일반 스윙 계산을 적용하지 않도록 상태 조건을 나눴습니다.

### 당겨 이동과 해제까지 연결

```text
조준·발사 → 지형 충돌
    ├─ 연결 불가: 갈고리 제거
    └─ 연결 가능: 거리·각도 저장
           ↓ 긴 줄은 먼저 당겨 길이 보정
         스윙
           ├─ 당김 입력 → 갈고리 위치로 접근 → 천장 부착
           └─ 버튼 해제 → 연결 해제 → 중력·낙하
```

당김 입력에서는 현재 위치에서 갈고리가 걸린 지점으로 향하는 방향을 다시 계산했습니다. 천장에 도착하면 중력을 끄고 플레이어의 머리가 천장 아래에 오도록 위치를 맞췄습니다. 이후 갈고리를 제거하고 천장 이동으로 전환했습니다.

줄을 놓으면 갈고리와 연결된 이미지를 제거하도록 예약하고 사슬팔의 연결 상태와 참조를 정리했습니다. 중력을 다시 켜고 점프·낙하 계산에 사용하는 누적 시간을 초기화해 떨어지도록 했습니다. 몸과 팔의 애니메이션도 스윙·해제·천장 부착에 맞춰 함께 전환했습니다.

발사 전에는 점선 조준선을 표시하고 지형에 걸린 뒤에는 플레이어와 갈고리를 실선으로 연결했습니다. 두 끝점에 같은 화면 스크롤을 반영하고 발사음과 지형에 걸리는 소리도 연결했습니다.

## 결과

사슬팔로 매달려 흔들리다가 입력에 따라 천장으로 당겨 올라가거나 줄을 놓고 낙하하는 이동을 구현했습니다. 이동 상태에 맞춰 몸과 팔의 애니메이션 및 조준선도 전환했습니다.
