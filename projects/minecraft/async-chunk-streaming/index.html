비동기 청크 스트리밍과 생성 파이프라인

문제 상황​

복셀 지형은 블록을 묶은 청크 단위로 관리했습니다. 카메라가 이동하면 주변 청크를 새로 준비하고 멀어진 청크는 제거해야 했습니다. 청크 하나는 32 × 256 × 32, 즉 262,144개의 블록 칸을 가집니다. 블록을 배치한 뒤에는 빛이 전달되는 범위와 화면에 드러나는 면을 계산하고 그릴 데이터를 GPU에 준비해야 했습니다.

이 계산을 메인 스레드에서 연속 수행하면 입력과 렌더링도 지연됩니다. 별도 계산을 맡는 워커 스레드로 작업을 옮기면서 계산 중인 청크가 먼저 제거되지 않도록 해야 했습니다.

접근 방법 검토​

블록 생성과 조명 및 메시 계산은 워커에서 수행하고 GPU 버퍼 준비는 메인 스레드에서 처리하도록 했습니다. 비동기 작업의 결과를 받는 future로 완료 여부를 확인하되 메인 스레드가 작업을 기다리며 멈추지 않도록 했습니다.

조명과 메시 계산은 이웃 청크의 블록도 참조합니다. 따라서 모든 작업을 동시에 실행하기보다는 계산 순서를 정하고 공유 중인 데이터를 추가하거나 제거할 시점도 함께 관리했습니다.

구성 요소맡긴 역할
CVoxelManager3청크 소유, 범위 요청, 작업 예약·완료 확인, 제거 조정
CChunk3블록과 단계별 상태, CPU 메시와 GPU 버퍼
CWorkerManager작업 큐와 워커 실행, future를 통한 결과 전달

해결 과정​

가까운 청크부터 최신 요청으로 준비​

활성 카메라의 X·Z 위치에서 중심 청크를 구하고 주변 원형 범위의 후보를 거리순으로 정렬했습니다. 요청을 처리할 때 가장 가까운 청크 하나를 선택해 점진적으로 생성했습니다.

카메라가 이동하면 아직 처리하지 않은 생성 범위를 최신 위치 기준으로 바꿨습니다. 지나온 위치보다 현재 카메라 주변의 지형을 먼저 준비하도록 했습니다. 이미 시작한 계산은 취소하지 않고 완료하도록 했습니다.

청크 객체와 블록 배열을 만들고 매니저에 등록하는 일은 메인 스레드에서 처리했습니다. 워커는 등록된 청크를 대상으로 계산합니다.

계산 단계를 future로 연결​

블록 생성이 끝나면 새 청크와 주변 8방향 청크를 조명 대상에 넣었습니다. 경계의 빛을 함께 계산하되 공유 데이터를 수정하는 조명 작업은 한 번에 하나만 진행했습니다. 메시 작업은 조명과 기존 메시 계산이 끝난 뒤 시작하도록 순서를 조정했습니다.

각 단계는 대기·진행·완료 상태를 NON / ING / DONE으로 기록했습니다. 이 상태로 다음 작업을 시작할 수 있는지 판단하고 future로 끝난 작업의 결과를 가져왔습니다. 대기 시간을 0으로 지정해 작업이 끝나지 않았어도 기다리지 않고 게임 루프를 이어가도록 했습니다.

C++
if (future.valid() &&
    future.wait_for(std::chrono::seconds(0)) == std::future_status::ready)
{
    auto completedChunkCoords = future.get();
    // 완료된 좌표의 청크를 찾아 다음 단계로 넘긴다.
}

메인 스레드에서는 계산이 끝난 메시로 GPU 버퍼를 생성했습니다. 불투명 블록과 텍스처의 투명 부분을 제외하고 그리는 블록 그리고 물을 구분해 버퍼를 준비했습니다. 버퍼 생성까지 완료된 청크부터 화면에 표시했습니다.

계산 중인 청크의 수명 관리​

블록 생성과 조명 계산 및 예약된 메시 작업이 모두 끝난 뒤 청크를 추가하거나 제거했습니다. 워커가 청크와 이웃 데이터를 읽는 동안 매니저의 청크 목록이 바뀌지 않도록 했습니다.

청크는 생성 범위보다 한 청크 더 멀어졌을 때 제거해 경계에서 반복 생성·제거되는 일을 줄였습니다. 제거 대상은 먼저 Dead로 표시해 새 조회에서 제외하고 이웃에서 새로 드러나는 면을 계산하도록 예약했습니다. 실제 삭제는 관련 작업이 끝난 뒤 수행했습니다. 플레이 중 블록을 편집할 때도 진행 중인 계산을 확인한 뒤 변경하고 메시를 다시 만들도록 했습니다.

결과​

블록 생성과 조명 및 메시 계산을 워커 스레드로 분리했습니다. 메인 스레드는 계산이 끝날 때까지 기다리지 않고 입력 처리와 렌더링을 이어가도록 했습니다. 카메라 주변의 가까운 청크부터 준비하고 완료된 결과를 화면에 반영했습니다.
