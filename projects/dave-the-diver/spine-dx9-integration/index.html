Spine 기반 물고기 애니메이션 구현

문제 상황​

데이브 더 다이버에서 물고기가 몸과 지느러미를 움직이며 역동적으로 헤엄치는 모습을 모작에도 꼭 담고 싶었습니다. 텍스처를 이동시키는 것만으로는 그 움직임을 표현하기 어려워 애니메이션 구현 방법을 찾아봤고 Spine 라이브러리를 DirectX 9 기반 프로젝트에 통합하게 됐습니다.

Spine을 도입하려면 기존 엔진의 리소스 관리와 렌더링 구조에 연결해야 했습니다. 같은 어종이라도 물고기마다 다른 동작을 재생할 수 있어야 했습니다.

접근 방법 검토​

애니메이션 재생과 본의 움직임에 맞춰 메시를 변형하는 계산은 Spine C++ 런타임에 맡겼습니다. 저는 파일·텍스처 로딩과 물고기별 재생 상태 및 기존 렌더러와의 연결을 구현했습니다.

구성 요소역할
CAssetSpine같은 어종이 공유하는 텍스처 배치와 본·애니메이션 원본 데이터
CSpine물고기별 현재 자세와 애니메이션 재생 상태
CDynamicBuffer변형된 메시를 GPU에 전달할 물고기별 버퍼
CFishGameObject물고기의 행동에 맞는 애니메이션 요청

원본 데이터는 공유하되 현재 자세를 담는 Skeleton과 재생 상태를 담는 AnimationState 및 정점 버퍼는 물고기마다 따로 만들었습니다. 한 물고기의 동작이 다른 물고기의 자세를 덮어쓰지 않도록 했습니다.

해결 과정​

엔진 리소스 로더에 연결​

텍스처의 배치 정보를 담은 Atlas를 먼저 읽고 본과 애니메이션 데이터를 불러왔습니다. Spine이 텍스처를 요청하면 기존 엔진의 CAssetTexture로 로드하도록 spine::TextureLoader를 연결하고 이미지 크기도 전달했습니다.

물고기 초기화에서는 선택한 어종의 정점·삼각형 수에 맞춰 버퍼를 준비했습니다. 정점에는 위치와 색상 및 텍스처 좌표를 담고 삼각형 연결 정보에는 16비트 인덱스를 사용했습니다. 매 프레임 변하는 정점을 갱신할 수 있도록 동적 버퍼로 생성했습니다.

애니메이션 재생과 렌더링 연결​

갱신 단계에서는 재생 시간을 진행하고 Skeleton에 애니메이션을 적용한 뒤 부모·자식 본의 움직임을 반영해 최종 자세를 계산했습니다.

CSpine.cpp의 애니메이션 갱신
m_pAniState->update(fTimeDelta);
m_pAniState->apply(*m_pSkeleton);
m_pSkeleton->updateWorldTransform();

렌더 단계에서는 Spine이 정한 그리기 순서대로 메시를 읽고 computeWorldVertices()로 변형된 정점을 얻었습니다. Spine이 계산한 자세에 물고기의 게임 내 위치와 회전을 반영하도록 월드 변환을 적용했습니다.

DirectX 정점변환한 데이터
위치Spine이 계산한 X·Y와 Z=0
텍스처 좌표(UV)Spine 메시의 텍스처 좌표
색상Spine 전체와 각 부위 및 메시에 지정된 색상을 곱하고 밝기 반영

물고기를 구성하는 여러 메시를 하나의 버퍼에 모았습니다. 이때 각 삼각형이 올바른 정점을 가리키도록 인덱스에 해당 메시의 시작 위치를 더했습니다. 삼각형 연결 정보는 초기화할 때 채우고 매 프레임에는 D3DLOCK_DISCARD로 이전 정점 데이터를 교체했습니다. 계산에 사용하는 임시 배열은 필요한 용량이 늘어날 때만 확장해 재사용했습니다.

행동과 피격 표현 연결​

물고기의 행동에서 swim과 die 같은 애니메이션 이름과 반복 여부를 전달했습니다. 같은 애니메이션을 매 프레임 다시 시작하지 않도록 행동 상태가 바뀔 때 애니메이션 전환을 요청했습니다.

밝기와 투명도는 정점 색에 반영했습니다. 피격 시에는 텍스처 색 대신 흰색 정점 색을 사용하도록 렌더링 설정을 바꿔 물고기를 하얗게 표시했습니다. 그린 뒤에는 텍스처 색과 정점 색을 곱하는 원래 설정으로 복구해 다른 객체의 렌더링에 영향을 주지 않도록 했습니다.

결과​

몸과 지느러미가 변형되는 유영 애니메이션을 기존 렌더러에 연결했습니다. 물고기별 행동에 따라 유영과 사망 동작을 전환하고 피격 시 색상 변화도 함께 표현했습니다.
